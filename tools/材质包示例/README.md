# 示例材质包 · 赛博方块

这个文件夹就是一个完整的材质包源目录，演示了如何做出「一个包含多套角色样式 + 主界面背景」的 `.bgpack`。

## 目录结构

```
材质包示例/
  pack.json        # 材质包清单（名称 / 作者 / 版本 / 背景 / 面板 / 样式列表）
  background.png   # 主界面背景（960x540 示例，1280 宽以内都行）
  styles/
    neon.png       # 角色样式 1 的贴图（64x64；游戏里按 30x30 绘制）
    blaze.png      # 角色样式 2 的贴图
```

## 打包成 .bgpack

在项目根目录执行（把 Pillow 的 python 换成你机器上的路径）：

```
python tools/make-pack.py tools/材质包示例 -o 赛博方块.bgpack
```

脚本会把 `pack.json` 里写的相对图片路径读出来、自动压缩到指定尺寸、转成 data URI，
最后输出**单个 JSON 文件**（后缀 `.bgpack`）。游戏安装时不需要解压，也不依赖网络。

## 安装

打开游戏 → 主菜单 → **🎨 材质包** → **📁 选择 .bgpack 文件**。
安装后点「启用」，再点想要的「角色样式」即可；主菜单背景会立刻换掉。

## 自己改

- 想换颜色/名字/作者：直接改 `pack.json`。
- 想加样式：把图片放进 `styles/`，在 `styles` 数组里加一项（`id` 不能重复）。
- 想隐藏右侧面板：把 `panels.mode` 改成 `"hide"`；想用自定义内容就改成 `"replace"`，
  再写 `"html"`（纯文本显示，不会执行 HTML，安全）。
- 图片别太大：整个包（含存档）序列化后不能超过 4MB，单张图建议 1MB 以内。
