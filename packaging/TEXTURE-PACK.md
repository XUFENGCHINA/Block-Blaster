# 材质包（Texture Pack）使用与制作说明

「方块枪神 2D」的材质包可以：

- 更换**主界面背景**（cover 铺满，保留暗色叠加，文字依旧清晰）；
- **隐藏 / 替换主界面右侧面板**（数据、难度纪录、大逃杀战绩、操作说明）；
- 提供**多套角色样式**（一个包内可切换，改角色方块的颜色或头像贴图，还可加发光）。

材质包是**单个 JSON 文件**，扩展名 `.bgpack`（内容与 `.json` 完全相同），图片以 **data URI 内嵌**，不依赖 zip、不依赖网络，电脑 / 手机 / PWA / EXE / APK 全部通用。

---

## 一、快速上手

1. 打开游戏 → 主菜单 → **🎨 材质包**。
2. 点 **📁 选择 .bgpack 文件**，选中别人做好的包（或先点 **✨ 载入示例包** 看效果）。
3. 在「已安装材质包」里点 **启用**；想关掉就点 **停用**，不用了就点 **删除**。
4. 在「角色样式」网格里点任意样式即可切换，选择会立刻保存。

---

## 二、`.bgpack` 格式

```json
{
  "format": 1,
  "name": "赛博方块",
  "author": "作者名",
  "version": "1.0",
  "background": "data:image/png;base64,...",
  "panels": {
    "mode": "hide",
    "html": "纯文本内容，可换行",
    "image": "data:image/png;base64,..."
  },
  "styles": [
    {
      "id": "neon",
      "name": "霓虹战士",
      "color": "#35e0f5",
      "dark": "#0a2c3a",
      "image": "data:image/png;base64,...",
      "glow": true
    }
  ]
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `format` | 建议写 `1` | 格式版本，目前只支持 `1` |
| `name` | ✅ | 材质包名称，安装后用于列表与存档 id（`name@version`） |
| `author` | 否 | 作者名，默认「匿名」 |
| `version` | 否 | 版本号，默认 `1.0`；同名同版本会覆盖安装 |
| `background` | 否 | `data:image/...` 背景图，`cover` 铺满主界面 |
| `panels` | 否 | 右侧面板处理方式，见下 |
| `styles` | ✅ | 角色样式数组，**至少 1 个**，`id` 不能重复 |

### panels 面板覆盖

| `mode` | 效果 |
| --- | --- |
| `hide` | 隐藏主菜单右侧**全部**面板 |
| `replace` | 隐藏原面板，显示 `html`（纯文本）或整张 `image`；两者可同时给（图在上、文字在下） |
| `keep` / 不写 `panels` | 保持原样 |

> 安全说明：`panels.html` 在游戏里**按纯文本渲染**，不会当作 HTML 执行（已做 XSS 防护）。
> 想写换行直接用 `\n` 即可；`<h3>`、`<img onerror=...>` 之类只会原样显示文字。

### styles 角色样式

| 字段 | 说明 |
| --- | --- |
| `id` | 样式唯一 id（英文/数字，不能与同包其它样式重复） |
| `name` | 样式显示名 |
| `color` / `dark` | 角色方块亮色 / 暗色（`#rgb`、`#rrggbb`、`rgb()/hsl()` 等）；建议用十六进制 |
| `image` | 可选，`data:image/...` 贴图（建议 32×32 或 64×64，PNG，透明背景）；有贴图时游戏按 30×30 绘制 |
| `glow` | 可选，`true` 时角色外圈加发光 |

图片建议压缩到 **1MB 以内**；整个存档序列化后超过 **4MB** 会被拒绝安装并提示。

## 三、怎么做一个材质包

### 方式 A：工具一键打包（推荐）

1. 建一个文件夹，例如：

   ```
   my-pack/
     pack.json
     background.png
     styles/neon.png
     styles/blaze.png
   ```

2. `pack.json` 里图片字段写**相对路径**（不要写 data URI）：

   ```json
   {
     "name": "我的材质包",
     "author": "我",
     "version": "1.0",
     "background": "background.png",
     "panels": { "mode": "keep" },
     "styles": [
       { "id": "neon", "name": "霓虹战士", "color": "#35e0f5", "dark": "#0a2c3a", "image": "styles/neon.png", "glow": true },
       { "id": "blaze", "name": "烈焰方块", "color": "#ff5b4a", "dark": "#4a1009", "image": "styles/blaze.png" }
     ]
   }
   ```

3. 在项目根目录运行（需要 Python + Pillow；脚本会自动压缩图片并转 data URI）：

   ```
   python tools/make-pack.py my-pack -o 我的材质包.bgpack
   ```

   常用参数：

   - `--max-width 1280`：背景图最大宽度（默认 1280）；
   - `--style-size 64`：角色贴图最大宽度（默认 64）；
   - `--no-resize`：完全不压缩，原图内嵌（注意 4MB 上限）。

4. 把生成的 `.bgpack` 发给朋友，或直接在游戏里安装。

### 方式 B：手工写 JSON

如果你的图片已经压得很小，也可以自己把图片转成 data URI（例如 `data:image/png;base64,....`），
按上面的格式拼一个 `.json` 文件，直接把后缀改成 `.bgpack` 即可。

### 方式 C：改示例包

`tools/材质包示例/` 是一个完整可用的示例源目录（1 张背景 + 2 套样式 + `pack.json` + README），
复制出来改名字、颜色、图片，再按方式 A 打包即可。

## 四、在各平台怎么安装

| 平台 | 做法 |
| --- | --- |
| 电脑浏览器 / 桌面 EXE | 主菜单 → 🎨 材质包 → 选择 `.bgpack` 文件即可（文件在电脑任意位置都行） |
| 手机浏览器 / PWA | 同样点「选择 .bgpack 文件」；先把文件下载到手机，文件管理里选中即可 |
| Android APK | 把 `.bgpack` 传到手机存储 → 游戏内 🎨 材质包 → 选择文件；App 已接入系统文件选择器（SAF，无需存储权限），可直接安装 |
| iOS | Safari 打开网页版 → 主菜单 → 🎨 材质包 → 选择文件（从「文件」App 选） |

安装记录保存在浏览器 / App 的本地存储（`localStorage`）里，换设备不会自动同步，重新安装即可。

> **PWA / 网页发版提示**：材质包入口上线后，老用户如果没有看到新界面，是因为 Service Worker
> 仍在用旧缓存。发版时请把 `sw.js` 的 `CACHE_NAME` 版本号 +1（当前 `bg2d-v5`），重新部署即可；
> 手机浏览器可以直接强制刷新一次。

## 五、限制与常见问题

- **提示「材质包过大」**：整个存档（包含关卡进度、图鉴等）序列化后不能超过 4MB。
  请把背景压到 1280 宽以内、单张图 1MB 以内，或用 `tools/make-pack.py` 自动压缩。
- **提示「缺少 name / styles」**：检查 `pack.json` 是否写了 `name`，`styles` 是否是至少 1 个对象的数组。
- **提示「不是有效的 JSON」**：文件有语法错误（多余逗号、中文引号等），可用在线 JSON 校验或编辑器检查。
- **背景换了但字看不清**：游戏会自动叠一层暗色渐变；如果原图太亮，建议自己把背景压暗一点。
- **角色还是方块没变头像**：样式里没有 `image` 时用 `color` 画方块是正常设计；有 `image` 时如果图片格式不对（不是 `data:image/...`），会回退成色块。
- **换包会不会丢进度**：不会。材质包只影响外观，删包 / 停用只恢复默认外观，不影响存档与关卡。
