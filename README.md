# 方块枪神 2D · Block Gunner

> 俯视角方块枪战：你是方块，敌人也是方块。**100 个关卡 · 50 种怪物图鉴 · 大逃杀 · 4 档外挂难度 · 装备/皮肤商店 · 局域网与内网穿透联机 · Windows/Android 双端安装包**。
> 纯 HTML5 Canvas + 原生 JS 实现，**零第三方依赖**，双击即玩。

## 🚀 三条命令跑起来

```bash
# 1) 起联机服务端（默认自动尝试 UPnP/NAT-PMP 或 cloudflared/ngrok/frpc 打通公网）
node server/server.js
# 2) 电脑玩：浏览器打开 http://127.0.0.1:8080/  （或双击 desktop/启动游戏.bat）
# 3) 手机玩：同一 WiFi 打开 http://电脑IP:8080/ → 主菜单「📲 安装到桌面」
```

联机：一端建房拿 4 位房间码，另一端用 `http://地址/#join=房间码` 直接进房。
俯视角方块枪战：**你是方块，敌人也是方块，用手枪把它们打成碎片。**
纯 HTML5 + Canvas 2D，零依赖、无需联网、双击即玩，**电脑与手机都能玩**。

## 运行

- 电脑：双击 `启动游戏.bat`，或直接双击 `index.html`（推荐 Chrome / Edge）
- 手机 / 平板：把整个文件夹传到手机，用浏览器打开 `index.html`；触屏会自动出现虚拟摇杆与按钮，**建议横屏**（竖屏会提示旋转），右上角有全屏按钮

## 大逃杀模式

- **超大地图**：三张地图可选 —— 中型 1800×1200（24 敌）/ 大型 2600×1700（38 敌）/ 超大 3400×2200（56 敌）
- 摄像机跟随 + **右下角小地图**（房屋 / 战利品 / 敌人 / 视野框）+ **屏幕边缘指南针**（指向最近的敌人并显示距离）
- **敌人散布很广不挤在一起**：出生间距 ≥92px，出生点 620px 内不刷敌人；未惊动的敌人只在小范围巡逻，你靠近 430px 或打它一下才会追杀你，远处的敌人自动休眠（手机也流畅）
- **开局只有一把小手枪**，房屋里随机刷战利品，武器池只有手枪和匕首：
  | 武器 | 特点 |
  | --- | --- |
  | 小手枪 | 开局自带，10 发弹匣，均衡 |
  | 手枪 | 12 发，稳定 |
  | 速射手枪 | 16 发，射速极快、单发低 |
  | 大口径手枪 | 8 发，单发 38 伤害 |
  | 匕首 | 近战，无限挥砍，一下 52 伤害，可劈到身前一片敌人 |
- **走过战利品自动换枪**，换下来的枪会掉在原地，可以随时走回去换回来（手机上不用额外按钮）
- **杀光所有敌人即可获胜**（分裂体死后会裂出小怪，也要清干净）
- 首次在某张地图吃鸡才发金币（中型 320 / 大型 600 / 超大 1100），重复吃鸡 0 金币

## 怪物图鉴（50 种）

主页面「📖 怪物图鉴」收录全部 **50 种方块怪**，按稀有度分为 普通 / 精锐 / 稀有 / 史诗 / 传说（普通 4 / 精锐 7 / 稀有 16 / 史诗 13 / 传说 10）。
**首次遇到某只怪就自动收录**（会弹「📖 图鉴新增」提示），卡片上有方块预览、血量 / 速度 / 接触伤害、特性标签、一句话打法描述和出现模式；没见过的怪显示 `???`，得去打过才解锁。

### 行为原型（50 种怪共用 5 套 AI，按数据驱动）
| 原型 | 行为 |
| --- | --- |
| 近战追击 | 直线冲过来用身体撞你，部分会瞬移 / 狂暴 / 自愈 / 护盾 |
| 远程射手 | 保持距离环绕走位，蓄力后开枪，部分带预判 / 追踪弹 / 穿墙弹 / 三连发 |
| 狙击手 | 蓄力更久但子弹极快、伤害高 |
| 分裂体 | 死亡后裂成 2~4 个碎片继续追你 |
| 自爆兵 | 死亡或贴身时爆炸，范围伤害 |

### 10 种个体特性（图鉴标签）
| 特性 | 效果 |
| --- | --- |
| 💊 自愈 | 每秒回复 1.5% 最大生命 |
| 🛡️ 护盾 | 每 7 秒获得一层可挡 1 次伤害的护盾 |
| ✨ 瞬移 | 每 4 秒闪现一段距离贴脸 |
| 🧲 追踪弹 | 子弹会拐弯追着你跑 |
| 👻 穿墙 | 子弹无视障碍物 |
| 🔥 狂暴 | 残血时移速与射速 +40% |
| 🔁 复活 | 死亡后以 50% 血量复活一次 |
| 🎯 预判 | 子弹预判走位，几乎不空枪 |
| 🥚 召唤 | 定期召唤小怪助战 |
| 🩸 吸血 | 命中玩家时回复自身生命 |

> 这些特性和难度关卡里敌人开的「外挂」共用同一套实现 —— 难度档是**全队**获得，图鉴里的怪是**自带**。
> 全部 50 种怪都有出场途径：战役关卡（后几关加入新怪）、难度关卡（按波次逐步解锁，每 5 波出 BOSS）、大逃杀（按地图大小解锁更强怪）。

## 金币规则

| 来源 | 金币 |
| --- | --- |
| 击杀敌人 | ❌ 不掉金币 |
| 战役关卡 · 首次通关 | ✅ 发（按每一波结算给到手） |
| 战役关卡 · 第 2 次及以后 | ❌ 0 金币（星级照常记录） |
| 难度关卡（无限） | ✅ 每清一波结算，乘档位倍率 |
| 大逃杀 · 首次吃鸡 | ✅ 发（按地图 320 / 600 / 1100） |
| 大逃杀 · 重复吃鸡 | ❌ 0 金币 |

公式在 `js/data.js`：`waveCoinReward()`（关卡/难度）与 `BR_MAPS[].reward`（大逃杀）。
例：第 1 关首通两波 `50 + 58 = 108`；难度第四档第 3 波 `(15+30) × 4 = 180`。

## 代码结构

```
index.html      页面骨架（HUD / 7 个页面 / 波次过渡 / 触屏控件 / 全屏与竖屏提示）
style.css       霓虹卡片风样式（自适应缩放，1em = 16px × 缩放比）
js/data.js      50 种怪物 / 特性 / 武器 / 外挂 / 难度档 / 障碍物 / 关卡 / 大逃杀地图 / 投放表 / 装备 / 皮肤 / 金币规则 / 存档
js/game.js      引擎：世界与摄像机、输入、音效合成、碰撞、外挂 AI、波次与金币、大逃杀、小地图、渲染、HUD
js/ui.js        页面路由、关卡页、难度页、大逃杀页、商店、结算与自动回退
tests/          自动化测试（Node 桩）与验证报告
preview/        界面预览图
```

想调数值直接改 `js/data.js`：`ENEMY`（敌人）、`WEAPONS`（武器）、`BR_MAPS`（大逃杀地图）、`DIFFICULTIES`（难度与外挂）、`LEVELS`（关卡波次）、`OBSTACLES`（地形）、`UPGRADES` / `SKINS`（商店）。
